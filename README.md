# 🗝️ 비밀의 보물상자 (NFC 퀴즈 게임)

ESP32 + NFC(PN532) + 서보모터 + 네오픽셀로 만드는 교실용 보물상자 퀴즈 게임입니다.
교사가 퀴즈와 정답을 출제하면 학생 화면에 문제가 나타나고, 학생이 **정답을 적은 NFC 카드**를 리더기에 대면
정답일 때 보물상자(화면 + 실제 서보)가 열리고 아이템을 획득합니다.

- 게임 파일: [`보물상자게임.html`](보물상자게임.html) — 단일 HTML, 더블클릭으로 바로 실행
- 웹에서 열기: https://goodssam012.github.io/nfc-treasure-chest/

## 사용 방법

1. MQTT 브로커(Mosquitto, WebSocket `ws://localhost:9001`)와 ESP32를 켭니다.
2. 페이지를 열고 오른쪽 위 **🧑‍🏫 교사 모드** → 비밀번호(처음 `1234`)를 입력합니다.
3. 문제·정답·힌트·아이템을 입력하고 **▶ 출제**를 누릅니다.
4. 학생은 정답을 쓴 NFC 카드를 리더기에 태그합니다.
   - 정답: 보물상자가 열리고 서보가 열림 각도로 회전, 네오픽셀 축하 조명, 아이템 획득
   - 오답: 상자가 흔들리고 네오픽셀이 빨갛게 깜빡임 (2번 틀리면 힌트 공개)

## MQTT 토픽

| 토픽 | 방향 | 용도 |
| --- | --- | --- |
| `esp32/sensor/nfc` | ESP32 → 웹 | NFC 카드 인식 (NDEF 텍스트 레코드를 정답으로 사용) |
| `esp32/control/nfc` | 웹 → ESP32 | 리더 리셋 `{"command":"reset"}` |
| `esp32/control/servo` | 웹 → ESP32 | 상자 열기/닫기 각도 |
| `esp32/control/neopixel/*` | 웹 → ESP32 | 대기·오답·축하 조명 (4×3) |
| `treasure/quiz` | 웹 ↔ 웹 | 현재 문제 (retained, 정답은 해시로만 전달) |
| `treasure/state` | 웹 ↔ 웹 | 상자 열림 상태 (retained) |

## 참고

- 브로커 주소는 화면 위쪽 입력칸에서 바꿀 수 있습니다.
- GitHub Pages(https)로 연 경우 `ws://localhost:9001`은 연결되지만, 다른 PC의 브로커(`ws://192.168.x.x`)는
  브라우저 보안 정책으로 막힐 수 있습니다. 이때는 HTML 파일을 내려받아 직접 여세요.
